# Issa & Warihinatou — Invitation numérique

Invitation au mariage religieux d’Issa et Warihinatou, le dimanche 20 décembre 2026 à Bobo-Dioulasso (Secteur 25).

À l’ouverture, la porte d’une mosquée s’ouvre sur l’invitation : affiche satin et or, compte à rebours, verset 30:21, lieu sur Google Maps et invocation pour les mariés.

## Utilisation

Tout tient dans un seul fichier : `index.html`. Ouvrez-le dans un navigateur, ou publiez-le avec GitHub Pages pour obtenir un lien à partager.

## Personnaliser

Au début du script, dans `index.html` :

```js
const CONFIG = {
  date: '2026-12-20',   // AAAA-MM-JJ
  heure: '',            // ex. '16:00' — vide = non affichée
  ...
};
```
